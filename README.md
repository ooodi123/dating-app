# Дейтинг Mini App для Telegram

Мини-апп знакомств внутри Telegram с AI-фичами и оплатой в Telegram Stars.
Продуктовый план и этапы — в [docs/PLAN.md](docs/PLAN.md).

```
server/   Node.js + TypeScript: Fastify API, бот на grammY, SQLite (better-sqlite3), Claude API
webapp/   React + Vite: сам мини-апп (лента, лайки, чаты, профиль, покупки)
```

## Быстрый старт локально (без Telegram)

Нужен Node.js 20+.

```bash
cd server && npm install && cp .env.example .env
# в .env поставьте DEV_AUTH=1 (и ANTHROPIC_API_KEY, если хотите проверить AI)
npm run seed      # 6 демо-анкет, трое уже лайкнули пользователя с id 1
npm run dev       # API на :3000

cd ../webapp && npm install && npm run dev   # http://localhost:5173/?dev=1
```

`?dev=<id>` — вход под любым тестовым пользователем. В продакшене `DEV_AUTH` должен быть `0`.

## Запуск в Telegram

Пошагово для Bothost — [docs/DEPLOY_BOTHOST.md](docs/DEPLOY_BOTHOST.md). На любом другом хостинге:
в корне `npm install` (соберёт всё) и `npm start`.


1. Создайте бота у [@BotFather](https://t.me/BotFather) и положите токен в `BOT_TOKEN` (только в `.env`
   или секреты хостинга — не в код и не в чат).
2. Задеплойте на сервер с HTTPS: `cd webapp && npm run build`, затем `cd server && npm run build && npm start`.
   Сервер отдаёт и API, и собранный мини-апп. Укажите этот адрес в `WEBAPP_URL`.
3. В @BotFather: `/newapp` (или Menu Button) → тот же URL.
4. Для AI добавьте ключ одного из провайдеров (необязательно, см. «AI-провайдеры» и «Бесплатный режим» ниже). Модель задаётся `AI_MODEL` (по умолчанию `claude-opus-5-5`;
   для экономии на большом трафике можно поставить `claude-haiku-5-5`).
5. Укажите свой Telegram id в `ADMIN_IDS` (узнать можно у @userinfobot): туда придут жалобы и заявки
   на верификацию с кнопками «Забанить» / «Подтвердить».

Оплата Stars не требует платёжного провайдера: бот создаёт invoice link с валютой `XTR`, мини-апп открывает
его через `Telegram.WebApp.openInvoice`, а начисление происходит по `successful_payment` в боте.

## AI-провайдеры
Провайдер выбирается по тому, какой ключ задан (или явно через `AI_PROVIDER`):

| Переменная с ключом | Провайдер | Модель по умолчанию | Цена |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | Claude | `claude-opus-5-5` | платно |
| `GEMINI_API_KEY` | Google Gemini | `gemini-flash-latest` | бесплатный лимит |
| `OPENROUTER_API_KEY` | OpenRouter | `google/gemma-4-31b-it:free` | бесплатно, ~50 запросов в день |
| `GROQ_API_KEY` | Groq | `llama-3.3-70b-versatile` | бесплатный лимит, без фото |

`AI_MODEL` меняет модель, `AI_PROVIDER=custom` + `AI_BASE_URL` + `AI_API_KEY` подключают любой
OpenAI-совместимый API. Проверка фото и селфи работает только с моделями, которые понимают картинки.

## Бесплатный режим (без ключа AI)
Без AI-ключа работает всё основное: анкеты, лента, свайпы, мэтчи, чат, лайки, рефералы,
жалобы и блокировки, оплата Stars. AI-кнопки (описание, совместимость, первое сообщение) просто скрыты,
AI-модерация пропускается, а верификация доступна только при заданном `ADMIN_IDS` (модератор проверяет
селфи вручную). Ключ можно добавить в любой момент: после передеплоя AI-фичи появятся сами.

## Модерация и доверие
- AI проверяет текст анкеты, фото и подозрительные сообщения. Без AI-ключа проверки
  пропускаются, и остаются только жалобы и модераторы.
- Верификация: селфи с жестом → AI-проверка → решение модератора в боте. Если `ADMIN_IDS` пуст,
  достаточно AI-проверки.
- Селфи хранятся в `SELFIES_DIR` и не раздаются наружу, их видят только модераторы.

## Безопасность
- Каждый запрос подписан `initData` Telegram; сервер проверяет HMAC и срок (24 ч).
- Тексты анкет передаются в AI как данные, а не инструкции; ответы строго по JSON-схеме.
- Повторный `successful_payment` с тем же `charge_id` не начисляет покупку второй раз.
