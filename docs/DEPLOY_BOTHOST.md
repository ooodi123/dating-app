# Запуск на Bothost

Сервер, бот и мини-апп работают одним процессом: Bothost ставит зависимости, сборка запускается
сама (`postinstall`), потом стартует `start.js`. Если хостинг не выполнит `npm install`, `start.js`
соберёт проект при первом запуске сам.

## Что понадобится
- Бот от [@BotFather](https://t.me/BotFather) (`/newbot`) — токен вставляется только в панель Bothost.
- Ключ нейросети для AI-фич и модерации (необязательно). Бесплатно — Gemini или OpenRouter, см. ниже.
- Свой Telegram id (у [@userinfobot](https://t.me/userinfobot)) — чтобы получать жалобы и заявки на верификацию.
- Тариф **Basic или выше**: на бесплатном данные стираются при перезапуске, а у нас там база,
  фото и селфи. На платных тарифах есть постоянный диск (volume).

## Шаги
1. **Новый бот в Bothost** → подключите репозиторий `ooodi123/dating-app`, ветка `main`.
2. **Язык / среда**: Node.js, версия **22.5 или новее** (нужен встроенный SQLite).
   Главный файл — `start.js` (если панель просит команду запуска — `npm start`).
3. **Токен бота** — в стандартное поле токена Bothost. Приложение понимает `BOT_TOKEN`,
   `TELEGRAM_BOT_TOKEN` и `API_TOKEN`.
4. **Домен**: в дополнительных настройках включите «Использовать домен», порт веб-приложения — **3000**.
   Адрес Bothost передаёт в переменной `DOMAIN`, приложение подхватит его само.
5. **Постоянный диск**: подключите volume и укажите путь к нему в переменной `DATA_DIR`
   (например, `/data`). Туда пишутся база, фото и селфи.
6. **Переменные окружения**:
   | Переменная | Значение |
   |---|---|
   | `GEMINI_API_KEY` | бесплатный ключ Gemini (или `OPENROUTER_API_KEY`, или платный `ANTHROPIC_API_KEY`) |
   | `ADMIN_IDS` | ваш Telegram id (несколько — через запятую) |
   | `DATA_DIR` | путь к постоянному диску |
   | `AI_MODEL` | необязательно; своя модель вместо стандартной |
   | `WEBAPP_URL` | необязательно; только если адрес не совпадает с `DOMAIN` |
7. **Деплой**. После изменения переменных нужен передеплой.

## Бесплатный ключ нейросети
**Gemini (рекомендую):**
1. Зайдите на [aistudio.google.com](https://aistudio.google.com) под Google-аккаунтом.
2. «Get API key» → «Create API key» → скопируйте ключ.
3. В Bothost добавьте переменную `GEMINI_API_KEY` с этим ключом и передеплойте.

Gemini недоступен в некоторых странах. Если в логах `User location is not supported` (это зависит
от страны сервера Bothost), используйте OpenRouter.

**OpenRouter (запасной):**
1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) → «Keys» → «Create Key».
2. В Bothost добавьте переменную `OPENROUTER_API_KEY` и передеплойте.
3. Бесплатно около 50 AI-запросов в день; если пополнить счёт на $10, лимит вырастет до 1000 в день.

## Проверка
- Откройте `https://<ваш-домен>/health` — должно быть `"bot": true`, ваш адрес в `webAppUrl` и провайдер в `ai`.
- В логах: `Bot @<имя> started`.
- Напишите боту `/start` → «Открыть приложение». Рядом с полем ввода появится кнопка «Открыть».
- Купите что-нибудь за Stars: на своём боте можно оплатить и потом вернуть звёзды.

## Если что-то не так
- **Первый запуск идёт 1–3 минуты** — если Bothost ставит зависимости до копирования кода, сборка
  происходит при старте (`Сборка приложения…` в логах). Это нормально.
- **«Нужен Node.js 22.5 или новее»** — смените версию Node в настройках.
- **Мини-апп не открывается** — проверьте, что домен включён и порт 3000; `/health` должен открываться.
- **Ошибка 409 Conflict в логах бота** — у этого токена работает другой экземпляр бота или задан webhook.
  Остановите другой экземпляр; приложение работает через long polling и снимает webhook при старте.
- **Пропали анкеты после рестарта** — `DATA_DIR` не указывает на постоянный диск.
